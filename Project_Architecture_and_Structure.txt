1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
FreightProxy.io is a modern, enterprise-grade full-stack Logistics & Proxy Shipping 
web platform paired with an end-to-end Playwright Automation Testing Framework.

Core Stack:
- Frontend: React 18, Next.js (App Router), Vanilla CSS / Tailwind Design Tokens
- Backend: Next.js Serverless Route Handlers
- Database: MongoDB via Mongoose ORM
- Authentication: Secure HTTP-Only JWT Cookie (`fp_session`) with Role-Based Guards
- QA Automation: Playwright (Page Object Model - POM Architecture)

3. APPLICATION ROUTE SPECIFICATIONS
================================================================================

1. `/` (Login Page)
   - Public Route.
   - Houses `LoginForm.js` and Platform Feature Showcase.
   - Validates credentials via `POST /api/login`.
   - On successful authentication, automatically redirects based on user role:
     * Admin   -> `/admin`
     * Manager -> `/manager`
     * User    -> `/dashboard`

2. `/register` (Registration Page)
   - Public Route.
   - Houses `RegisterForm.js` with client-side password strength calculation.
   - Creates new Customer accounts via `POST /api/register`.
   - Automatically redirects to `/` upon successful creation.

3. `/dashboard` (Customer Portal)
   - Protected Route (Requires Active Session).
   - Houses `DashboardView.js` with live 7-Stage Pipeline tracker.
   - Includes Interactive Volumetric Price Engine Modal:
     Formula: `Volumetric Weight = (Length × Width × Height) / 5000`
     Pricing: `Base ($25) + Chargeable Wt × $12.50 + Surcharges`

4. `/manager` (Freight Dispatch Operations Hub)
   - Protected Route (Requires Admin or Manager Role).
   - Houses `ManagerPage.js`.
   - Features:
     * Freight Operations Pipeline: Advance order stages (7 stages).
     * Order Specs Editor: Modify origin, destination, and shipping price.
     * Customer & Staff Roster inspection.

5. `/admin` (Master Control Center)
   - Protected Route (Strictly Requires Admin Role).
   - Houses `AdminPage.js`.
   - Features:
     * User Management: Invite/Add new users, promote/demote roles inline.
     * Account Status: Toggle accounts between `Active` and `Suspended`.
     * Global Orders Master: Real-time global shipment visibility.
     * Audit Trail: Real-time system action logging.

6. `/profile` & `/settings` (User Account Management)
   - Protected Routes.
   - View user metadata, update departments/names, toggle 2FA preferences, 
     and change passwords.


================================================================================
4. BACKEND API ENDPOINTS
================================================================================

- `POST /api/login`         : Authenticates user, issues secure `fp_session` cookie.
- `POST /api/register`      : Registers new customer user account.
- `POST /api/logout`        : Clears session cookie and invalidates session.
- `GET  /api/auth/me`       : Returns sanitized current user session payload.
- `GET  /api/auth/demo-info`: Public endpoint returning SuperAdmin hint.
- `GET  /api/orders`        : Retrieves orders (scoped by user email or role).
- `POST /api/orders`        : Creates new shipment order with volumetric pricing.
- `PUT  /api/orders`        : Updates pipeline stage or order specifications.
- `GET  /api/users`         : Lists all users (Admin/Manager session required).
- `POST /api/users`         : Admin creates new staff/manager account.
- `PUT  /api/users`         : Admin updates user role or toggles active/suspended.
