   FREIGHTPROXY.IO - ORDER CREATION STUDIO, SIDEBAR & ENTERPRISE UPGRADE TASKS

1. FEATURE OVERVIEW & ARCHITECTURAL OBJECTIVES
--------------------------------------------------------------------------------
Upgrade FreightProxy.io into a full-width, enterprise-grade logistics platform 
with a dedicated Creation Studio, modern Left Sidebar for Admin/Manager, 
smart Search/Filter Toolbars, dedicated View/Edit Detail Modals/Pages, 
Advanced Carrier Rates Engine, Brand Favicon & Meta Assets, 100% Mobile/Tablet 
Responsiveness, and strict role-based access control.

Key Core Pillars:
1. Role-Based Order Scoping:
   - Regular User (Customer): Strictly sees ONLY their own shipment orders.
   - Admin & Manager: Has global visibility over ALL system orders across customers.

2. On-Behalf Order Creation (Admin & Manager):
   - Admin/Manager can create shipments for any existing customer via a 
     searchable user picker.
   - If customer is not registered, Admin/Manager enters customer details 
     (Name, Email, Phone), and backend automatically provisions/creates the 
     new customer account and links the order seamlessly.

3. Two-Tier Order Actions: Dedicated "View Details" & "Edit Specs":
   - 👁️ "View Order": Opens complete order in full read-only Waybill/Timeline mode 
     (Customer info, 7-Stage pipeline timestamps, Volumetric breakdown, Barcode).
     Includes a top-right action button to transition into Edit mode or Advance Pipeline.
   - ✏️ "Edit Order Specs": Opens Edit mode. Customer details (Name, Email, ID) are 
     STRICTLY READ-ONLY (Locked for audit integrity). Only order specs (Origin, 
     Destination, Weight, Dimensions, Addons, Total Price) can be updated.

4. 100% Multi-Device Responsive Design (Zero Clipping / Zero Horizontal Cut-Off):
   - Fluid responsive data tables with smooth touch scrolling and Mobile Card View.
   - Collapsible slide-out Left Sidebar drawer on Mobile/Tablet with touch gesture.
   - Dynamic fluid grid systems across 320px (Mobile), 768px (Tablet), 1024px (Laptop), 
     and 1440px+ (Ultra-Wide Desktop).

5. Brand Identity & High-Resolution Favicon Suite:
   - Modern, crisp SVG & PNG Favicon / App Icon (Electric Indigo 3D Freight Cube).
   - Configured in Next.js App Router root layout and metadata.

6. Professional Left Sidebar Layout (Admin & Manager Hubs):
   - Modern, collapsible/fixed Sidebar Navigation containing:
     * 📦 Shipments & Pipeline
     * ➕ Order Creation Studio
     * 🚚 Manager Operations Hub
     * 👑 Admin Control Center
     * 👥 Customer & Staff Roster
     * 📜 Security Audit Trail
     * ⚙️ Profile & Settings
     * 🌙 Theme Toggle
   - Customer Portal: Retains clean, user-friendly shell as-is with full-width 
     Creation Studio access.

7. Full-Width Orders Filter & Search Toolbar:
   - Live Search by Tracking ID, Package Title, Customer Email, Origin/Destination.
   - Status Filter Pills: All, Pickup Pending, Warehouse, Dispatched, Delivered.
   - Sorting: Newest First, Price High/Low, Weight High/Low.

8. Full-Page Dedicated Order Creation Studio:
   - Replace basic modal popup with a full-page dedicated creation studio 
     (`/create-order` or `/dashboard/create-order`).
   - Side-by-side live volumetric calculation breakdown, preset box sizes, 
     and live barcode/waybill preview card.

3. MARKET RESEARCH & INDUSTRY BENCHMARK REFERENCE
================================================================================

Industry Study: Modern Logistics & Freight Platforms (2026 Standards)

1. Flexport (International Freight Forwarding Standard)
   - Benchmark: End-to-end multi-modal visibility, dedicated full-page booking 
     studio, and internal team collaboration notes.
   - Applied to FreightProxy: Full-page Order Studio, multi-carrier rate cards, 
     and operational staff activity log.

2. ShipBob (Fulfillment & 3PL Portal Standard)
   - Benchmark: Clean left sidebar navigation, fast searchable order inventory, 
     and 1-click printable warehouse dispatch labels.
   - Applied to FreightProxy: Modern Left Sidebar Shell, full-width filter toolbar, 
     and printable waybill sheets.

3. Shippo (Carrier Rate & API Engine Standard)
   - Benchmark: Dynamic live pricing based on volumetric dimensional weight, 
     preset carton quick selectors, and transparent fee breakdown.
   - Applied to FreightProxy: Centralized `lib/pricing.js`, preset box dimension 
     pills, and real-time volumetric calculation gauge.

4. AfterShip (Post-Purchase & Exception Tracking Standard)
   - Benchmark: Visual multi-stage status progress bars, real-time exception 
     hold alerts (Customs, Weather), and customer status visibility.
   - Applied to FreightProxy: 7-Stage Pipeline visual tracker with timestamped 
     dates and warning badges for delayed packages.
